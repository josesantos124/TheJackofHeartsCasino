# The Jack of Hearts Casino
The Jack of Hearts Casino is a Python-based virtual casino application developed as part of A-Level Computer Science coursework.
The project simulates realistic casino games while focusing on probability, randomisation, and structured game logic.
It also explores ethical considerations in software design, particularly around gambling addiction and responsible gameplay.

Key features:

Multiple casino-style games implemented in Python

Probability-based outcomes and randomisation

Modular, object-oriented design

User input handling and game state management

Ethical focus on responsible gambling concepts

Technologies used:

Python

Object-Oriented Programming (OOP)
